# 🎓 LehrplanPLUS-Referenz

InfoCraft orientiert sich am bayerischen LehrplanPLUS des ISB (https://www.lehrplanplus.bayern.de). Ziel: Jede Funktion ist einer Jahrgangsstufe und Kompetenz zuordenbar.

## Grundsätze

1. Jedes Modul dokumentiert, welche Inhalte es abdeckt (siehe Tabelle unten).
2. Neue Funktionen bekommen vor der Umsetzung einen Lehrplan-Eintrag (Jahrgangsstufe, Fach, grobe Kompetenz). Erst dann wird gebaut.
3. Prüfungs- und Quiz-Modus decken dieselben Kompetenzen ab wie der Übungsbetrieb, damit die Prüfungsvorbereitung curricular identisch ist.
4. Die inhaltliche Feinabstimmung erfolgt durch die Fachlehrkraft, das Repository liefert die Struktur.

## Modul-Zuordnung (wird je Phase verfeinert)

| Modul | Bereich (LehrplanPLUS Informatik) | Beispiele |
| --- | --- | --- |
| SQL-Werkstatt | Datenbanken | Datenerfassung und -verwaltung, SQL-Grundlagen, Modellierung |
| HTML-Werkstatt | Webseiten gestalten | HTML, CSS, Layout |
| Code-Werkstatt | Algorithmen, Programmieren | Java-/Python-Grundlagen, Kontrollstrukturen |
| Quiz-Arena | übergreifend | Wiederholung, Wissenssicherung |
| Wiki und Präsentationen | übergreifend | Fachbegriffe, Konzepte |

Hinweis: Die konkrete Zuordnung zu Jahrgangsstufen (6 bis 10, später Oberstufe) wird pro Feature ergänzt, sobald die jeweilige Phase startet. Diese Datei ist die zentrale Referenz und wird mit jedem Release aktualisiert.
